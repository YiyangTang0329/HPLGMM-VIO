## Materials for Review

To facilitate the review process, all relevant materials have been made publicly available in this repository. The files are organized as follows:

- **`Detailed_Response.pdf`**  
  A complete response letter providing detailed point-by-point responses to all comments raised by the Associate Editor and the reviewers.
  
- **`Condensed_Manuscript_No_Color.pdf`**  
  The clean version of the revised manuscript prepared in compliance with the 20-page limit of *IEEE Transactions on Robotics*, without color-coded revision marks.

- **`Condensed_Manuscript_with_Color.pdf`**  
  The marked-up version of the 20-page revised manuscript, in which the changes made during the current revision round are highlighted in red font.

- **`Supplementary_Materials_No_Color.pdf`**  
  The clean version of the supplementary material, including mathematical proofs, simulation validation, and additional experimental evaluations that further support the conclusions of this work.
  
- **`Supplementary_Materials_with_Color.pdf`**  
  The marked-up version of the supplementary material, in which the changes made during the current revision round are highlighted in red font.

- **`Full_Manuscript_No_Color.pdf`**  
  The clean and complete version of the manuscript, incorporating all mathematical proofs, simulation studies, experimental results, and supporting analyses, without revision marks.

- **`Full_Manuscript_with_Color.pdf`**  
  The marked-up complete version of the manuscript, in which the changes made during the current revision round are highlighted in red font.
